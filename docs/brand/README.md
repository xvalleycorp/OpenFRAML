# OpenFRAML brand

The mark is an open ring, the O of OpenFRAML, with a single gap where a payment leaves the bank. A dot sits in the
gap: the checkpoint every payment passes before it is sent. Open system, nothing leaves unchecked.

## Files

| File | Use |
| --- | --- |
| `openframl-logo.svg` | Logo on light backgrounds |
| `openframl-logo-on-dark.svg` | Logo on dark backgrounds |
| `openframl-logo-mono.svg` | One colour: print, stamps, embossing |
| `openframl-mark.svg` · `-on-dark` · `-mono` | Mark alone, where the name is already shown |
| `openframl-icon.svg` · `openframl-icon-512.png` | App icon, avatars, social cards |
| `favicon-32.png` | Browser favicon |

The wordmark is set in [Sora](https://fonts.google.com/specimen/Sora) (SIL Open Font License), Regular for "Open"
and Bold for "FRAML", tracking −3 %, and converted to outlines, so the files need no font installed.

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Ink | `#0A2540` | Ring, wordmark, dark backgrounds |
| Signal | `#0D9488` | The checkpoint dot; one accent per screen |
| Mist | `#F4F5F7` | Light backgrounds |
| White | `#FFFFFF` | Ring and wordmark on Ink |

## Rules

- Keep clear space around the logo equal to the ring's stroke × 2 (a quarter of the mark's height).
- Smallest size: mark 16 px, full logo 24 px high.
- Keep the gap on the right. Do not rotate the mark, close the ring, or move the dot inside it.
- Signal is only ever the dot or a single accent; never colour the ring or the wordmark with it.
